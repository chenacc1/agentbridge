## 一、项目定位（一句话）

**AgentBridge 是一个本地优先的手机远程操控工具：手机通过微信扫一个二维码，就能实时查看、继续、停止电脑上正在运行的 AI 编程 Agent（Claude Code / OpenAI Codex / DeepSeek Harness / DSH Desktop 会话 / ZCode 入口），并批准高风险操作、切换模型——全程不暴露电脑本体，Agent 凭据永远留在本机。**

数据流向：

```text
手机（微信扫一扫 → H5 控制台）
        │  HTTPS/HTTP（可信局域网 / Tailscale / ZeroTier / Cloudflare 隧道）
        ▼
AgentBridge 本地服务（电脑，默认 127.0.0.1:8787）
        │  stdio / 本机 loopback 通道
        ▼
各家 Agent 子进程（codex app-server、claude -p、dsh --profile acp、DSH Desktop 插件、ZCode 原生入口）
```

核心设计哲学（来自 PRODUCT.md）：

1. 电脑是唯一执行端；
2. 每个远程动作都是「有范围、可归因、幂等、可见」的；
3. 只展示适配器真实支持的能力；
4. 断线重连靠有序事件日志恢复状态，而不是重放命令；
5. 降级必须显式：不可用的 Agent、不支持的审批，绝不伪装成可用。

## 二、解决的客户痛点

| 痛点 | AgentBridge 的解法 |
|---|---|
| AI 编程任务跑几分钟以上，人离开屏幕只能干等 | 手机 H5 控制台实时看流式输出、工具调用、任务状态，随走随看 |
| 想继续/纠正任务，必须回到电脑前 | 手机发消息即续接同一会话；Claude 会话级 `--resume`、Codex `thread/resume` |
| 多厂商 Agent 各自为政（Claude、Codex、DSH、ZCode） | 统一适配层 + 一条规范化 append-only 事件流，一个控制台管全部；电脑端与手机端消费同一条流 |
| 手机和电脑同时操作同一会话会冲突 | 输入租约（control lease）：同一时刻只允许一个设备写；显式「接管输入」并显示持有者；租约 5 分钟自动续期 |
| 断网重连后状态丢失 | SSE 事件流 + 单调递增 seq 游标，重连按 `after=seq` 补拉，不重不漏；消息可补拉，审批/工具/停止等状态事件不可丢 |
| 担心手机侧获得过大权限 | 项目别名白名单（手机只能提交 `alias`，不能提交任意路径）；设备 token 只存 SHA-256 摘要；跨源 POST 一律 403；停止需两次点击；高危审批「仅本次批准」 |
| 电脑关机/网络不便 | 远程三模式（Tailscale / ZeroTier / Cloudflare 隧道）让手机跨网访问，但服务始终留在私有网络或带密钥门禁，不上公网 |

## 三、架构梳理（按源码分层）

### 3.1 目录与模块地图

```text
src/
  server.js                 HTTP + SSE 服务骨架、路由与鉴权（约 490 行）
  config.js                 环境变量配置加载、loopback 判定、LAN 地址选择
  event-store.js            append-only 事件日志（JSONL 落盘 + 内存环形 + 订阅广播）
  pairing.js                一次性配对码、设备会话（SHA-256 摘要持久化）、吊销
  session-manager.js        会话创建/attach、幂等命令、控制租约、停止、审批路由、模型切换
  adapter-registry.js       适配器注册与能力探测
  dsh-desktop-channels.js   DSH Desktop /phone 专用通道：token 轮换、命令队列、事件去重
  cc-switch-models.js      CC Switch（Kimi）当前厂商只读模型目录
  cli.js                    agentbridge CLI：phone / setup / install-*-skill
  adapters/
    echo.js                 内置演示适配器（安全验证全链路）
    codex.js                OpenAI Codex App Server（stdio JSON-RPC）
    claude.js               Claude Code CLI（stream-json 流式）
    deepseek-harness.js    官方 dsh --profile acp（NDJSON JSON-RPC）
    dsh-desktop.js          DSH Desktop 当前会话绑定适配器
    zcode-native.js        ZCode 官方原生远控入口（诚实标注，不伪造接入）
    process-utils.js       子进程探测/启动（Windows 原生入口直连，避免 npm shim 长驻 stdio）
public/
  index.html / app.js      响应式玻璃质感 H5 控制台（桌面/手机同一套代码）
  markdown.js              受限 Markdown 渲染器（原始 HTML 一律转义）
  command-id.js            客户端命令 ID 生成（crypto.randomUUID 缺失时的兼容实现）
bin/agentbridge.js         CLI 入口
scripts/
  start-agentbridge.ps1    一键启动器（健康检查、防双开、日志、远程模式探测）
  install-agentbridge-shortcut.ps1  桌面快捷方式安装（本地 + 三个远程模式）
  install-dsh-phone.mjs / uninstall-dsh-phone.mjs  DSH Desktop 插件幂等安装/卸载
integrations/dsh-phone/    @agentbridge/dsh-phone：DSH Desktop /phone 插件包
docs/                      架构方案、发布指南、Tailscale 调研、产品讲解页
test/                      50+ 个 Node 内置测试（配对、事件、租约、幂等、SSE、安装器、各适配器）
*.cmd                      四个 Windows 一键启动入口
```

### 3.2 事件协议（统一语义层）

所有 Agent 的行为被归一化为带 `seq` 的事件写入 JSONL 日志，并向 SSE 订阅者广播。事件类型：

- `session.created / session.ready / session.failed`
- `turn.started / turn.completed / turn.cancelled / turn.failed`
- `message.started / message.delta / message.completed`
- `tool.started / tool.completed`
- `approval.requested / approval.resolved`
- `control.granted / turn.stop_requested / model.changed`

每个状态变更命令都带 `commandId`，服务端按 commandId 去重（幂等），重复请求返回首次结果。

### 3.3 安全边界（逐层）

| 层 | 机制 | 源码位置 |
|---|---|---|
| 配对 | 一次性配对码，默认 5 分钟有效，用后即失效；二维码不含 Agent 凭据 | `pairing.js` |
| 设备会话 | 随机 256-bit token，`HttpOnly; SameSite=Strict` cookie，默认 72 小时；**只把 SHA-256 摘要落盘**（`.agentbridge/sessions.json`），原始 token 不持久化 | `pairing.js` / `server.js` |
| 端点边界 | 配对、bootstrap、本地 `/phone`、DSH register 等全部 loopback-only；手机路径永不可达 | `server.js` 路由表 |
| 项目白名单 | 手机只提交 `alias`；仅 `/phone` 本机路径可注册临时别名（需 loopback + 真实目录） | `config.js` / `registerLocalProject` |
| 请求防护 | 所有 POST 要求同源；JSON body 限长；变更命令 commandId 幂等 | `requireSameOrigin` / `readJson` |
| 并发控制 | 控制租约（默认 5 分钟）：同一会话只有一个设备可写；显式接管需确认 | `session-manager.js` |
| 高危操作 | UI 停止需两次点击；审批「仅本次批准」；Claude MVP 权限提示直接拒绝 | `public/app.js` / 各适配器 |
| 公网模式 | Cloudflare 隧道自动启用共享密钥门禁：非 loopback 请求必须带 key，泄露 URL 本身不够 | `AGENTBRIDGE_ACCESS_KEY` / `hasAccessKey` |
| 设备治理 | 桌面「已配对设备」列表，任意设备（如丢失的手机）一键吊销 | `POST /api/devices/:id/revoke` |

### 3.4 适配器能力矩阵（与 README 一致）

| 适配器 | 传输 | 流式 | 审批 | 续接 | 取消 | 说明 |
|---|---|---|---|---|---|---|
| Echo | 进程内 | ✅ | ✅ | ❌ | ✅ | 内置演示，安全验证全链路 |
| OpenAI Codex | `codex app-server --stdio` | ✅ | ✅ | ✅ | ✅ | 真实 thread/turn/item、模型+推理档位选择 |
| Claude Code | `claude -p --output-format stream-json` | ✅ | MVP 拒绝 | ✅ | ✅ | 续接用 `--resume`；30 秒首包看门狗防挂起 |
| DeepSeek Harness | `dsh --profile acp` | ✅（已提交块） | ✅ | ✅ | ✅ | 官方 ACP 持久 stdio 连接 |
| DSH Desktop `/phone` | 本机 loopback 插件通道 | ✅ 同会话 | — | ✅（同会话） | ✅ | 绑定屏幕上正在打开的会话，双向同会话同步 |
| ZCode | 官方原生入口 | — | — | — | — | 不伪造接入；引导官方 Remote Control / Bot Channel |

## 四、核心功能与亮点（客户视角）

### 4.1 扫码即用

- 桌面页生成一次性配对二维码（微信扫码打开 H5），5 分钟内有效、一次一用；
- 配对成功后该手机 72 小时内免登录；
- 微信关闭页面后可通过固定「手机常用入口」二维码/收藏地址直接回到最近会话，无需再扫配对码；
- 桌面可随时吊销任意已配对设备。

### 4.2 多 Agent 统一控制面

- 一个控制台管理多个厂商 Agent；能力如实标注（「未安装」「暂未接入」「原生入口」）；
- 手机可切换会话、发消息、停止（两次点击）、批准/拒绝高风险请求、切换模型；
- Codex 会话可选手动选择模型 + 推理强度（来自本机 Codex 账户真实 model/list）；
- Claude 会话在检测到 CC Switch（Kimi）配置时，提供会话级模型切换（只影响后续手机回合，不动全局配置）。

### 4.3 `/phone` 斜杠命令（最有体感的功能）

在 Claude Code / Codex 桌面 / DSH Desktop 里输入 `/phone`：

- 自动拉起本地 Bridge（若未运行）；
- 绑定**当前项目目录 + 当前会话**（Claude 用官方 `${CLAUDE_SESSION_ID}`，DSH 读 live Agent 的 `session.id`/`cwd`/`provider`/`model`）；
- 输出一张 5 分钟一次性二维码（终端 ANSI + 临时 SVG 图片 URL + 手机配对地址）；
- 扫码后手机自动选中该会话并持有输入租约；
- 不猜测、不抓 GUI、不碰厂商私有格式。

### 4.4 远程三模式（同一安全模型）

| 模式 | 适用 | 手机要求 | 说明 |
|---|---|---|---|
| 同网直连 | 手机与电脑同一 Wi-Fi | 浏览器 | 手机用 `http://192.168.x.x:8787` |
| Tailscale / ZeroTier | 跨网、同 tailnet/网络 | 装对应 VPN 应用 | 服务走 `100.x.y.z` / ZeroTier 受管 IP，不上公网 |
| Cloudflare 隧道 | 手机不想装任何应用 | 只需浏览器 | `https://<random>.trycloudflare.com`；自动加共享密钥门禁；保留 loopback-only 配对边界 |

### 4.5 工程可靠性亮点

- **零运行时依赖**：Node.js 22 原生 + 唯一依赖 `qrcode@1.5.4`（锁版本）；
- **一键启动器**：`.cmd` 双击即启动——健康检查、防端口 8787 双开、日志写 `.agentbridge/logs`、自动打开控制台；
- **50+ 自动化测试**：覆盖配置、一次性配对、事件持久化/游标、项目白名单、loopback 注册、适配器 attach/resume、DSH 通道认证与事件映射、安装/卸载幂等、CLI 技能生成、命令幂等、控制租约、HTTP 全链路、SSE 重放；
- **诚实降级**：ZCode 行显式标注为官方原生入口；不可用适配器在 UI 上禁用创建并给出说明；Claude 首包 30 秒超时失败可见、不留手机空等。

## 五、使用方法（客户操作步骤）

### 5.1 最快上手（本地同网）

```powershell
# 电脑：Node.js 22+
npm install
$env:AGENTBRIDGE_PROJECTS = "agentbridge=D:\codex_project\手机远程操控agent"
npm start          # 或双击根目录「启动 AgentBridge.cmd」
```

- 电脑浏览器打开 `http://127.0.0.1:8787`，看到一次性二维码；
- 手机与电脑在同一可信局域网，用微信「扫一扫」→ 进入手机控制台；
- 选项目别名 → 选 Agent → 发消息 / 看流式输出 / 停止 / 审批 / 切模型。

Windows 一键：双击 `启动 AgentBridge.cmd`；运行 `scripts\install-agentbridge-shortcut.ps1` 可在桌面创建 4 个快捷方式（本地 + 三个远程模式）。

### 5.2 安装 `/phone` 技能

```powershell
# Claude Code
node .\bin\agentbridge.js install-claude-skill --user
# Codex 桌面
node .\bin\agentbridge.js install-codex-skill  --user
# DSH Desktop
npm run install:dsh-phone
```

重启对应工具后，在项目会话里输入 `/phone` 即得二维码。

通用 CLI 入口：

```powershell
node .\bin\agentbridge.js phone --agent echo          # 安全演示
node .\bin\agentbridge.js phone --agent codex         # 新建 Codex 会话
node .\bin\agentbridge.js phone --agent codex --session <thread-id>   # 续接已知会话
node .\bin\agentbridge.js phone --agent deepseek-harness
```

### 5.3 远程使用

1. **Tailscale**：电脑与手机装 Tailscale 并登录同一 tailnet → 双击桌面「AgentBridge Remote」→ `/phone` 生成编码 `http://100.x.y.z:8787` 的二维码；
2. **ZeroTier**：两设备加入同一 ZeroTier 网络并勾选 Auth → 双击「AgentBridge Remote ZeroTier」→ 同上；
3. **Cloudflare**：`winget install --id Cloudflare.cloudflared` → 双击「AgentBridge Remote Cloudflare」→ 手机浏览器打开 `https://<random>.trycloudflare.com`（可带启动器窗口打印的访问密钥），再扫 `/phone` 二维码。

### 5.4 常用配置项（`.env.example`）

| 变量 | 默认 | 含义 |
|---|---|---|
| `AGENTBRIDGE_PORT` | 8787 | 监听端口 |
| `AGENTBRIDGE_PROJECTS` | 当前目录 `workspace` | `alias=绝对路径` 分号分隔白名单 |
| `AGENTBRIDGE_PUBLIC_ORIGIN` | 首个 LAN IPv4 | 编码进二维码的地址 |
| `AGENTBRIDGE_PAIRING_TTL_MS` | 300000 | 配对码 5 分钟 |
| `AGENTBRIDGE_SESSION_TTL_MS` | 259200000 | 设备会话 72 小时 |
| `AGENTBRIDGE_ACCESS_KEY` | — | 公网模式共享密钥门禁 |
| `AGENTBRIDGE_CLAUDE_MODEL` | 保留 provider 配置 | 可选 Claude 模型覆盖 |

## 六、界面说明（H5 控制台）

玻璃质感（sx-glass）移动优先设计，同一套代码响应式适配桌面/手机：

- **顶部**：机器名、连接状态（实时同步 / 正在重连）、会话计数；
- **配对面板**（桌面）：一次性配对二维码 + 手机常用入口二维码 + 已配对设备列表（可撤销）；
- **会话侧栏**：状态点（启动中/就绪/执行中/失败/离线）+ 标题 + 适配器·项目；
- **事件时间线**：消息（Markdown 安全渲染）、工具开始/完成、审批卡片（仅本次批准 / 拒绝）、状态事件；
- **输入区**：发送（非控制权持有者禁用 + 「接管输入」按钮）、停止（两次点击确认）、模型选择器（仅支持的适配器显示，回合空闲 + 持有控制权才可切）。

可访问性：键盘可达、焦点保留、≥44px 触控目标、颜色+中文文字双通道、`prefers-reduced-motion` 降级。

## 七、现状与边界（对客户诚实声明）

- 本地 MVP，明文 HTTP，仅适用于**可信局域网 / 私有 VPN / 带密钥门禁的 Cloudflare 隧道**；**不要把 8787 端口直接映射公网**；
- Agent 凭据与子进程全部留在电脑；
- 暂未提供：多用户授权、事件日志静态加密、Bridge 重启后恢复运行中子进程、官方公众号/企业微信渠道（架构文档 `docs/architecture/wechat-multi-agent-remote-control.md` 已作为后续阶段规划）。

## 八、讲解稿（3 分钟口播版，可直接对客户念）

> 各位好，今天介绍的工具叫 **AgentBridge——手机远程操控 Agent**。
>
> **它解决什么问题？** 大家在电脑上跑 AI 编程 Agent——Claude Code、Codex、DeepSeek Harness——任务往往要跑几分钟甚至更久，人离开屏幕就只能干等。这个工具让你**用微信扫一个二维码，手机上就能实时看到 Agent 在干什么、继续给它下指令、中途喊停、批准它要做的危险操作、甚至切换模型**——全程不用把电脑本身暴露到网上。
>
> **它怎么做到的？** 电脑本地跑一个轻服务，各家 Agent 的消息、工具调用、审批请求全部归一化成一条事件流，电脑和手机同步消费这条流。手机和电脑同时操作也不会打架，因为它有「输入租约」机制：同一时刻只允许一个设备写；断网重连后按序号自动补拉，不重不漏。
>
> **四个亮点**：第一，**扫码即用**——一次性二维码 5 分钟内有效，手机 72 小时免登录，设备随时可吊销；第二，**多 Agent 统一**——一个控制台管多个厂商，能力如实标注，没接好的绝不装样；第三，**远程三模式**——同网直连、Tailscale/ZeroTier 私有网、Cloudflare 隧道（手机甚至不用装任何应用）；第四，**安全可控**——Agent 凭据永远留在电脑，手机只能访问白名单项目，每个操作都有幂等防重放保护。
>
> **怎么用？** 电脑上双击「启动 AgentBridge」，手机用微信扫桌面二维码进入控制台；在 Claude Code 或 Codex 里敲 `/phone`，二维码直接绑定你当前这个项目、这段对话。手机上点「停止」是两次点击确认，点「批准」只对这一次动作生效。
>
> **现状**：它是可本地运行的成熟 MVP，配套 50 多个自动化测试；远程模式均保持服务在私有网络内，不上公网。后续规划是多用户权限、静态加密和官方微信渠道。
>
> 一句话总结：**电脑是唯一的执行端，手机是一个安全、可审计、随时可收回的控制面。** 谢谢。
